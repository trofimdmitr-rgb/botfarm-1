# Дизайн-код BotFarm

Правила для любого нового экрана, макета или редизайна мини-аппа. Их выбрал Антон (10–11.11.2026), действующий стиль —
«как Яндекс Музыка» (раздел 4). Читать перед любой работой с внешним видом.

## 1. Зачем и для кого

- Мастер (продавец) сначала смотрит на функционал и исполнение. Исполнение он оценивает первым, поэтому оно должно быть
  очень красивым и приятным с первого экрана.
- Клиент мастера должен захотеть **показать** страницу или билет подруге. Это главный источник новых клиентов (виральность).
- Порядок важности: клиент → мастер → админ платформы. Клиентские экраны — максимум характера. Панель мастера — тот же
  стиль, но спокойнее: мастер смотрит туда по 20 раз в день, ему важна читаемость.
- Дизайн не должен выглядеть сделанным нейросетью: это отталкивает.

## 2. Как работаем (обязательно)

1. **Бриф.** Перед любым дизайном задать Антону вопросы: для кого экран, какие ниши, что нравится или не нравится.
   Не делать «слоп» наугад. Антон просит **задавать больше вопросов** — лучше 2 коротких раунда вопросов
   с вариантами, чем угадывать.
2. **2–3 направления в разных стилях.** Референсы не смешивать в одно; на каждое направление — свой стиль.
   Цвета и шрифты можно менять.
3. **Сразу назвать всё, что может оттолкнуть хотя бы 1%** (читаемость, ниша, слабые телефоны, непонятные элементы),
   и спросить.
4. **Утверждение**, затем один экран; дальше остальные.
5. **Проверка:** `npm run e2e` (контраст, обрезанный текст, размер кнопок, нижняя панель), просмотр скриншотов
   `e2e-screens/` глазами на маленьком Android и iPhone.

## 3. Анти-«нейронка»: чего не делать

- Карточки с одинаковыми скруглениями и тенью, фиолетово-синий градиент «по умолчанию», эмодзи вместо иконок.
- Один шрифт на всё, «Inter везде», заголовок + подзаголовок + три карточки с иконками.
- Пустые слова: «Добро пожаловать!», «Лучший сервис», «Ваш надёжный партнёр».
- Иконки ради иконок. Если подпись понятна, иконка не нужна.

**Что делать вместо этого** — решения, которые ИИ делает плохо, а человек замечает сразу:
- Типографика: одна-две семьи с ясными ролями (контраст 900 ↔ 400 вместо «зоопарка шрифтов»), ровные цифры (tabular-nums).
- Фактура: зерно, мягкий свет, размытие. Не плоские заливки.
- Предметные метафоры: ближайшая запись — «мини-плеер», после записи — постер для сторис со штрихкодом.
- Тихое движение: текучие пятна, перелив внутри кнопок, параллакс — медленно и не бросается в глаза.
- Живые тексты (см. п. 6).

## 4. Действующий стиль клиентской части — «как Яндекс Музыка» (11.11.2026)

История: 10.11 выбрано направление «Розовый свет» (постер PinkPantheress). 11.11 Антон прислал скриншоты Яндекс Музыки
(«Моя волна», «Что послушать») и попросил: тексты и шрифтовые пары как там, больше тихих анимаций с текучими градиентами.
Ответы Антона на вопросы: шрифт Golos; имя крупно жирным по центру, без рукописного; тёмный фон по умолчанию, светлый по
выбору; кнопка — длинная таблетка с ближайшим временем; обложка — фон за именем; нижняя панель — иконки с подписями;
разделы — подборки с жирными заголовками; анимации — текучее пятно, перелив в кнопке/карточках, параллакс обложки,
появление блоков при прокрутке.

### Шрифт — одна семья Golos Text (ParaType, бесплатный, кириллица)

YS Display/YS Text (Яндекс) брать нельзя — закрытый шрифт. Golos — ближайший по ощущению, одна семья, как у Яндекса.

| Роль | Начертание | Где |
|---|---|---|
| Имя мастера, «Вы записаны!», «Во сколько?», заголовки подборок («Работы ›», «Прайс») | 900, межбуквенное −0.04…−0.045em, высота строки 0.9–1.1 | имя 36–76 px (по длине), шаги 36 px, подборки 28 px |
| Кнопки, строки списков, время | 500–700 | 17–19 px |
| Текст, подписи | 400–500 | 14–17 px, цифры `tabular-nums` |

Тексты крупные, как в Яндекс Музыке: строки списка 17 px, описание 17 px. Подписи с большой буквы.

### Цвет (`web/palette.ts`, «Настройки → Цвет страницы»)

- Режим: **Тёмная** (по умолчанию; фон #0b0b0d, белый текст) или **Светлая** (пастель).
- Цвет: Розовый, Сиреневый, Мятный, Янтарный, Небо, Графит, «Из обложки», свой. У каждого цвета **три ярких цвета
  пятна** (розовый: малиновый + коралловый + фиолетовый; янтарный — жёлтый + красный + розовый, как «Моя волна»).
- Кнопка «Записаться» — перелив двух ярких цветов, текст чёрный или белый — что контрастнее (считается автоматически).
- Шаблоны: бьюти — розовый, барбер — графит, репетитор — небо, массаж — сиреневый, авто — янтарный.

### Светлые палитры по референсам (12.11.2026) и Ч/Б

Антон прислал 4 референса (ягнята с розовым «ТРЕНДЫ» и звёздами-вспышками; дофаминовая клетка голубой/розовый/жёлтый;
мята с сиренью; пыльная роза + бирюза + слоновая кость с японскими волнами) и попросил ~10 палитр + ч/б.
Решение: эти палитры **только светлые**, у каждой свой **узор** на фоне.

| Палитра | Фон / текст | Пятна | Кнопка | Узор |
|---|---|---|---|---|
| Луг | шалфей / тёмно-оливковый | розовый, трава, белый | розовая, тёмный текст | звёзды-вспышки |
| Клетка | молочный / почти чёрный | голубой, розовый, жёлтый | розовый→жёлтый | клетка |
| Мята и сирень | мята / тёмно-зелёный | сирень, мята, лаванда | сирень→мята | искры |
| Пыльная роза | слоновая кость / сливовый | роза, бирюза, розовый | пыльная роза, белый текст | волны (сэйгайха) |
| Журавли | серо-голубой / синий | голубой, роза, шалфей | серо-синяя | волны |
| Волны | лавандовый / индиго | голубой, розовый, мята | индиго | волны |
| Персик | персик / коричневый | коралл, сирень, крем | коралловая | точки |
| Тигр | серо-сиреневый / тёмный | красный, оранжевый, голубой | красная | звёзды |
| Лимонад | лимонный / тёмный | жёлтый, розовый, голубой | тёмная | клетка |
| Сакура | розовый / бордовый | розовый, мята, абрикос | розовая | искры |
| Ч/Б | белый/чёрный — по переключателю | оттенки серого | чёрная / белая | точки |

Контраст проверен скриптом: текст/фон ≥ 10, вторичный ≥ 6, текст кнопки ≥ 3.7 (крупный жирный). Цвет текста кнопки
выбирается автоматически (`pickText`).

### Анимации — живые, но тихие (только transform / opacity / background-position)

- **Живой фон на весь экран** (`web/motion.tsx → LiveBackground`): 5 пятен цвета палитры плывут и «дышат» по всему
  экрану (12–25 с), поверх — узор палитры. При прокрутке узор едет в 3 раза медленнее текста, пятна — ещё медленнее.
- **Текучее пятно за именем** (`.g-blob`) — как раньше; на постере и в пустых «Моих записях» тоже.
- **Блеск** на главных словах: имя мастера, «Записаться» (светлая полоса раз в ~5 с), «Вы записаны!» и время на постере
  (отблеск по буквам раз в ~6,5 с). Делается копией текста в `::after` (`data-text`), основной текст не трогаем.
- **Позвонить**: строка «Позвонить +7…» с круглой иконкой цвета кнопки и тихой волной-пульсом; тап — звонок (`tel:`),
  номер заодно копируется (если звонилка не открылась — «Номер скопирован — можно вставить»).
- **Загрузка**: вместо крутилки — заглушки-строки с бликом; фото проявляются из размытия; время и фото работ
  появляются лесенкой.
- **Переход между экранами через затемнение** (`.g-veil`): новый экран проявляется из тёмной вуали за 0,55 с.
- **Свайп влево/вправо между вкладками** (Главная ↔ Работы ↔ Запись ↔ Мои записи): экран тянется за пальцем,
  после свайпа новый въезжает с нужной стороны. Не срабатывает с края экрана, на каруселях, днях, полях и в просмотре фото.
- Параллакс обложки и пятна, появление блоков при прокрутке — как раньше.
- `prefers-reduced-motion` выключает всё; в автотестах блоки видны сразу.

### Решения 12.11 (по отзыву Антона и Дмитрия)

- **Выбор цвета — живые превью**: в настройках у каждой палитры маленькая страница (фон, узор, переливающиеся пятна,
  «Аа», кнопка). «Из обложки» и свой цвет тоже переливаются и получают узор-искры цвета палитры.
- **Значки — один стиль на всё**, мастер выбирает в «Настройки → Значки»: обычные, тонкие, жирные, двухцветные,
  в кружочках (`html.ic-*`). Больше никаких «этот значок залитый, а тот контурный».
- **Контакты — все строки одинаковые**: кружок со значком, сверху подпись (Адрес / Позвонить / Ссылка), снизу значение.
- **Работы — без скруглённой рамки**: неровный мягкий край (две маски-эллипса), который медленно «дышит».
- **Кнопки никогда не сливаются с фоном**: кнопка цвета текста — надпись цвета фона; нижняя кнопка Telegram — цвет
  «Записаться» с подобранным цветом надписи.
- **Панель мастера в той же стилистике**: заголовки разделов жирным без капса, кнопки-таблетки, залитые скруглённые поля,
  карточки 22 px, дни и вкладки — таблетки, ошибка поля — красной строкой без плашки.

### Экраны клиента

- **Главная:** фон шапки (обложка: середина фото, ниже размыта под вуалью; пятно) → огромное имя по центру →
  описание серым по центру → «Записаться | сегодня 10:00» → «мини-плеер» ближайшей записи (квадрат с датой + время +
  услуга, как трек внизу Яндекс Музыки) → контакты группой строк с иконками → «Работы ›» каруселью →
  «Прайс» + таблетка «Все N» → группа строк → «Онлайн-запись без звонков».
  Без белого ореола вокруг текста, без строк `@slug`/«запись открыта» сверху.
- **Запись:** «Шаг N из M» + вопрос 900. Дни — таблетки (выбранный залит белым), время — сетка таблеток по
  Утро / День / Вечер, выбранное заливается переливом. Поля — залитые скруглённые.
- **Вы записаны:** постер с текучим пятном: «Имя, ждём вас», ДЕНЬ + время огромным, услуга и адрес, штрихкод с номером.
  «Скриншот этой карточки — готовая сторис», кнопка «Позвать с собой».
- **Мои записи:** предстоящие — «мини-плееры» с кнопкой «Отменить», история — группа строк со статусами.
- **Нижняя панель:** иконки с мелкими подписями, текущая — белая и чуть крупнее.

## 5. Панель мастера

Та же палитра и шрифт (заголовки Golos 900), но без пятна и зерна. Плотные списки, крупные понятные действия.
Главное — скорость и читаемость.

## 6. Тексты

- Коротко, по-человечески, без канцелярита и восклицаний ради восклицаний: «Что делаем?», «Почти всё», «до встречи»,
  «позвать с собой», «запись онлайн, без звонков».
- Без рода, где его нельзя знать: не «записалась», а «Вы записаны»; не «позвать подругу», а «позвать с собой».
- Цифры точные: «сегодня 17:30», «10 окон», «№ 0147».
- Ошибки — что случилось и что сделать: «Это время только что заняли — выберите другое».
